🔊 TTS 语音合成（GPT-SoVITS）

让 LLM 的回复"说出来"：本地 GPT-SoVITS 服务（api_v2.py）把回复文本合成成人声播放。GPT-SoVITS 作为外部服务运行（独立端口），本页统一管理其开关与参数。默认关闭。

保存即写入 .env 并即时生效（无需重启后端）。

启动 GPT-SoVITS 服务方式：python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml。「测试服务」会先探测端口连通性，再真实合成一小段验证参照音频配置。

🎙️ 每角色 TTS 独立服务（GPT-SoVITS）

每个角色独立启动一个 GPT-SoVITS 服务（独立端口 + 独立权重/语言/参照音频）。配置「tts 模型执行文件」「权重文件」「参数/参照音频」后用「启动」按钮拉起；合成时按角色自动选用对应服务。
